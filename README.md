# E-commerce Analytics Project (SQL, PostgreSQL)

## Описание проекта

Аналитическое исследование e-commerce данных с фокусом на бизнес-метрики: выручка, LTV, retention rate, RFM-сегментация и поведение пользователей.

Цель проекта — выявить ключевые драйверы выручки, оценить качество клиентской базы и найти точки роста бизнеса.

---

## Решаемые задачи

- Анализ выручки и сезонности
- Расчёт AOV и LTV
- Когортный анализ retention
- Сегментация клиентов (RFM)
- Анализ категорий товаров
- Выявление вернувшихся покупателей

---

## Стек

## Основные инсайты

### 1. Сильная зависимость выручки от отдельных пиков
Обнаружены аномальные всплески выручки (например, Black Friday), которые формируют значительную долю дохода.

Вывод: бизнес зависит от акций и распродаж.

---

### 2. Низкая доля повторных покупок
Большая часть пользователей делает только 1 заказ.

Вывод: слабое удержание клиентов.

---

### 3. Сильная сегментация по LTV
- Основная масса пользователей — low-value
- Небольшая группа даёт значительную долю выручки

Вывод: бизнес зависит от high-value клиентов

---

### 4. RFM-анализ
Выделены сегменты:
- low frequency / low monetary (основная масса)
- high value сегмент (ядро бизнеса)

Вывод: есть потенциал для CRM и retention-механик

---

### 5. Топ категории
- health_beauty
- watches_gifts
- bed_bath_table

Вывод: ключевые категории драйвят revenue
